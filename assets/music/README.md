# Musik (Audiio-Instrumentals)

Die vier Tracks liegen **nicht im Repo** (damit das Klonen schnell geht),
sondern im GitHub-Release „workshop-medien“. Für Drill 10 bei Bedarf hierher
laden:

```sh
cd assets/music
curl -fLO https://github.com/jhoetter/pfefferminzia/releases/download/workshop-medien/Audiio_Bigsby_BounceBack_Inst.flac
curl -fLO https://github.com/jhoetter/pfefferminzia/releases/download/workshop-medien/Audiio_FadedAeon_Imagination_150bpm_G.flac
curl -fLO https://github.com/jhoetter/pfefferminzia/releases/download/workshop-medien/Audiio_King-Chino_King-Chino_Dusty_Instrumental.flac
curl -fLO https://github.com/jhoetter/pfefferminzia/releases/download/workshop-medien/Audiio_The-Artist--Me-_Get-Down_Sucka-Free_Instrumental.flac
```

Das Beispielvideo nutzt `Audiio_Bigsby_BounceBack_Inst.flac` (112,5 BPM).
Die Dateien sind verlustfreie FLACs der Original-WAVs (`SHA256SUMS` gilt für
die entpackten WAVs: `flac -d --keep-foreign-metadata *.flac`).

Die Tracks unterliegen der Audiio-Lizenz: nur in eigenen Produktionen
verwenden, nicht als Rohdateien weitergeben.
